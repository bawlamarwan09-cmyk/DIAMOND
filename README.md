# Lab Grant Diamond

Responsive Next.js App Router bridal experience using the black, bronze and champagne design with local cinematic media.

## Development

Use the installed pnpm version specified in `package.json`.

- `pnpm dev:next` — standard Next.js development.
- `pnpm build` — production Next.js static export to `out/`.
- `pnpm dev` — compatible supervised Sites/Vinext preview of the same App Router source.

## Experience

- Wedding-led hero with couple imagery and cinematic motion.
- Bridal collection paths for engagement rings, wedding bands and the wedding day.
- Editorial diamond-cut guide with oval, round, marquise and emerald imagery.
- Scroll-driven ring reveal with local H.264 video and WebP posters.
- Responsive collection cards and accessible ring-detail dialogs.
- Three pinned craft chapters with direct chapter navigation.
- Film viewer with the generated cinematic clips.
- Reduced-motion preference, manual motion control, in-view playback and static fallbacks.
- Search metadata, canonical URLs, robots.txt, sitemap.xml and Product structured data.

No payment or booking backend is included.
